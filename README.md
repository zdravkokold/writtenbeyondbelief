# Written Beyond Belief

Act as a high-end UI/UX Designer and Developer specializing in zen, minimalist, and holistic health/wellness websites. 

Build a complete multi-page web application using the attached text files, logo, hero photo, and homepage layout reference.

---

### 🎨 DESIGN PHILOSOPHY & VIBE:

- Aesthetic: Calm, authentic, spacious, open, and gentle.

- Whitespace: High usage of padding (generous vertical spacing between sections) so the design has "room to breathe".

- Typography: Elegant serif for headings (e.g., Cormorant Garamond or Playfair Display) and clean, soft sans-serif for body text.

- Image Blending: Photos (especially hero and portrait images) MUST NOT have sharp, boxy borders. Apply soft edge blending using CSS masks/radial-gradients so photos merge smoothly into the background.

---

### 📁 CURRENT PHASE ASSETS & FALLBACKS:

1. Logo: Use the uploaded logo in the header and footer.

2. Hero Photo: Use the uploaded cliff photo full-width in the top section of the Home Page.

3. Temporary Backgrounds (until Phase 2 files are uploaded):

   - Use soft, subtle CSS watercolour-like gradient backgrounds (warm off-white, soft beige, and pale muted tones).

   - Set up CSS background overlay containers ready for SVG watermarks.

---

### 📍 STRUCTURE & NAVIGATION:

- Navigation Header: Logo + Links: "About Me", "The Work I Offer", "Contact".

- Home Page Layout:

  1. Top Section (Hero): Full-width hero photo with short intro text.

  2. Second Section ("My Mission"): Follow the structure and layout shown in the attached layout screenshot.

- Footer Links: Privacy & Cookie Policy, T&C / Refund Policy, Client Disclaimer & Informed Consent.

- Contact Page: Clean contact form linked to sending emails.
